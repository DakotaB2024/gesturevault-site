GestureVault App Store website

The support email and privacy policy are filled in.

GitHub Pages:
1. Create a public GitHub repository, for example gesturevault-site.
2. Upload index.html, support.html, privacy.html and style.css to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose main and / (root), then Save.
6. After GitHub publishes the site, use support.html as the App Store Connect Support URL and privacy.html as the Privacy Policy URL.

The privacy policy was drafted from a source review of the supplied GestureVault project. If the production app later adds analytics, advertising, cloud sync, new network services, or other data handling, review and update the policy before shipping that change.
